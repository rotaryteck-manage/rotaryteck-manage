# 14.4v

只修正工作回報照片，不調整料件、電鍍、線材等其他上傳流程。

- 工作回報每張照片以 750 KB 為壓縮上限。
- 原壓縮程序仍超標時，繼續縮小整張照片尺寸並重新編碼，不裁切。
- 全部照片壓縮通過後才送出回報；錯誤顯示照片檔名與原因，保留回報內容和待上傳照片供重試。
- JPEG 轉檔使用 .jpg 檔名，避免內容與附檔名不一致。
- 後端 800 KB 限制、權限、回報排版、通知及其他區域壓縮器維持原樣。

## 檢查項目

1. 右上角版本顯示 14.4v。
2. 使用原本無法上傳的大照片建立工作回報，確認可正常儲存並看到完整照片。
3. 一次選取多張照片、手機直接拍照及電腦貼圖仍可使用，最多10張規則不變。
4. 不可讀取的照片顯示檔名與原因，工作進度文字、已選照片仍在。
5. 移除或更換失敗照片後可重新儲存，不會先留下只有部分照片的回報。
