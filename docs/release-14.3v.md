# 14.3v

## 修改

- 共用雲端儲存改為角落「儲存中…」提示，不使用中央阻擋視窗。
- 從表單送出時先保留原表單並關閉遮罩，可查看及捲動目前頁面。
- 儲存中保留寫入保護；可以展開文字紀錄與既有唯讀內容。上傳期間仍需保持頁面開啟。
- 儲存失敗時保留待儲存資料及原請求編號；原表單仍在時恢復表單，提供既有重試方式。
- 線材紀錄總覽最後兩個按鈕明確設為底部對齊，避免共用 align-self:stretch 樣式使按鈕偏高。
- 未修改實際寫入 API、通知、權限、資料排序與合計規則。

## 檢查項目

1. 官網右上角版本為 14.3v。
2. 新增或修改後儲存，不再出現中央上傳遮罩，右下角顯示小提示。
3. 儲存完成小提示消失，顯示既有成功提示，重新載入後資料仍在。
4. 儲存中可捲動目前頁面、展開紀錄；再次寫入會被攔住。
5. 若網路儲存失敗，表單與待儲存資料保留，可按重試，不會重複新增。
6. 線材紀錄總覽「匯出目前表格」「全部線材使用量」與其他欄位底部對齊；手機仍兩欄。

驗證：完整測試 486 項通過，建置成功。新增測試涵蓋非阻擋提示、成功清理、失敗表單復原、不覆蓋新表單、寫入攔截與重試沿用同一請求編號。
