# v84 統一更新包：通知、手機拍照與輸入表單縮放

日期：2026-10-01

本包已包含尚未更新的 v83，只需套用本包一次，不必先裝 v83。

## 更新內容

- 包含 v83：完整通知公開金鑰、前後端/建置驗證、中文提示、等待通知服務啟用；安卓工作回報修正「直接拍照」「從相簿選擇」。
- 工作回報最多 10 張照片、拍照/相簿共用預覽、照片必填及大於 800 KB 自動壓縮保持原設定。
- 手機表單輸入文字統一為 16px，降低 iPhone 點入工作進度時自動放大的問題。沒有禁止使用者雙指縮放。
- 手機彈窗適應可見畫面與鍵盤高度；內容區可上下滑動，標題、關閉、取消與儲存列固定在彈窗內。
- 文字框填滿可用寬度，避免欄位或長說明把畫面向右撐開；月曆字體與版面不更動。

## 套用方式

1. 解壓 rotaryteck-notifications-camera-mobile-v84-changes.zip。
2. 將解壓後的檔案與資料夾放到現有 GitHub 專案根目錄，依相同路徑覆蓋；不要刪除其他檔案。
3. 本包的 build.mjs、wrangler.jsonc、worker、dist、tests、更新紀錄 都要一起更新，不要只上傳 CSS。
4. 沿用 Cloudflare 建置命令：node apply-android-v80.mjs && npm run build；部署命令：npm run deploy。
5. 部署成功後，將手機網站或桌面捷徑關閉重開，再檢查通知按鈕、拍照及工作進度輸入。

本包沒有私人金鑰、登入密碼或使用者資料。沒有新增資料庫遷移，沒有更動通知收件人權限，也不會向大家發送測試通知。Cloudflare VAPID_PRIVATE_KEY 必須仍與公鑰屬於同一組。
