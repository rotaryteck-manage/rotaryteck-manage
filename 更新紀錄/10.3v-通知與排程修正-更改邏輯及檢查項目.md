# 10.3v 通知與排程修正

## 本版範圍

本版只處理以下四項，不更動既有通知文字、通知條件、權限、工作介面及其他已完成的功能。

1. 每次從其他管理區重新進入「工作排程」時，自動切到每日排程並選取台北時區的今天。
2. 修正「文字記錄」按鈕在保留月曆畫面時重複增加；同時保護「重置本週排程」及「整理重複排程」不重複。
3. 定時通知改為逐條驗證與執行；一條舊規則格式異常時，只略過該條，不再中止其他正常規則。
4. 「補發」改為先檢查今天的缺漏通知，列出內容後由主管勾選發送。

## 更改程序邏輯

### 一、進入工作排程

1. 系統偵測網址由其他區域切換成 `#schedule`。
2. 只在「剛進入工作排程」時把頁籤設為每日排程，日期設為台北時區今天。
3. 留在工作排程內切換月份、日期或每週排程時，不強制跳回今天。
4. 離開工作排程後再次進入，才重新回到今天。

### 二、文字記錄及每週工具

1. 每次畫面重繪先尋找既有按鈕。
2. 已存在時重用原按鈕，不再新增第二顆。
3. 若舊畫面已累積多顆，保留第一顆並移除其餘重複按鈕。
4. 權限不足或頁籤不適用時隱藏既有按鈕，不改動原權限判定。

### 三、自動通知

1. Cloudflare 排程仍為每 5 分鐘執行一次。
2. 每條儲存的通知規則分開驗證。
3. 格式正常且已啟用的規則繼續進入原本的時間、對象、權限、內容與去重判定。
4. 格式異常的單一規則會記錄錯誤並略過，不影響其他規則。
5. 工作提醒、工作回報、線材、電鍍及自訂提醒共用此修正後的定時管線。
6. 國定假日與停班規則使用同一批已驗證規則，再各自執行原有來源檢查。
7. 料件紀錄維持新增後即時通知；假別維持新增／異動／取消即時通知及排程重試，本版未改其條件。

### 四、缺漏補發

1. 主管按規則旁的「補發」後，伺服器重新用今天資料計算應發內容。
2. 套用原本的到點時間、對象、權限、規則異動防回補及當日初始接收人鎖定。
3. 逐一比對每台啟用裝置的永久去重憑證，只列出尚未成功送達的項目。
4. 畫面顯示接收人、分類、訊息、項目數、待補發裝置數、曾失敗及達重試上限狀態。
5. 主管勾選後，伺服器再次計算及驗證，避免開啟視窗後狀態改變造成錯發。
6. 手動補發成功後，同步完成原自動通知的去重憑證；下一次五分鐘排程不會重送。
7. 通知紀錄標示「自動發送」或「手動補發」。
8. 只檢查今天，不補發歷史日期；已成功的裝置不重複發送。

## 部署程序

此包是接續目前完整 10.2v 專案的差異更新包。

1. 先備份目前專案及 Cloudflare D1。
2. 將壓縮檔內容保持資料夾結構覆蓋到目前專案根目錄。
3. 執行 `npm install`（若相依套件已完整可略過）。
4. 執行 `npm test`，應顯示 289 項通過、0 項失敗。
5. 執行 `npm run build`。
6. 依原有方式重新部署 Worker；本版沒有新增資料庫 migration。
7. 手機與電腦完全關閉舊頁面後重新開啟，確認名稱／職位旁顯示 `10.3v`。

- [ ] 每週頁面的「重置本週排程」及「整理重複排程」各只有一個。

### B. 每日工作自動通知

- [ ] 建立今天的一筆工作並指派給測試人員。
- [ ] 將每日工作提醒設為台北目前時間後下一個容易觀察的時間，保持啟用。
- [ ] 不按「立即檢查通知」、不按「補發」，等待設定時間後最多約 5 分鐘。
- [ ] 當事人收到一則通知，後台與鈴鐺出現同一筆紀錄。
- [ ] 再等下一輪五分鐘排程，不會收到重複通知。

### C. 工作回報、線材與電鍍

- [ ] 工作回報：有今日工作但尚未回報的人員，到設定時間會自動收到；已有回報者不收到。
- [ ] 線材：只有「需補貨、未訂購、未入庫」且符合天數的線材會自動通知；通知以符合筆數統整。
- [ ] 電鍍：只有已送鍍未回貨且符合天數的紀錄會自動通知。
- [ ] 點通知後，工作、線材及電鍍仍前往原規則目前設定的位置。
- [ ] 上述測試均不使用「補發」來代替自動發送。

### D. 缺漏補發

- [ ] 按規則旁「補發」，先出現今天缺漏清單，不再先列全部人員。
- [ ] 若全部已正常送達，顯示「今天目前沒有缺漏通知」。
- [ ] 若有缺漏，清單可逐項勾選，並顯示人員、訊息與待補發裝置數。
- [ ] 未勾選任何項目時不能送出。
- [ ] 補發完成後再次開啟，成功項目不再出現在缺漏清單。
- [ ] 通知紀錄顯示「手動補發」；正常排程紀錄顯示「自動發送」。
- [ ] 新增主管或倉管後，不會把今天以前的舊通知補發給新幹部。

### E. 未改功能抽查

- [ ] 料件新增仍依原設定即時通知。
- [ ] 假別新增／異動／取消仍只通知當事人及主管，舊假別不回補。
- [ ] 通知文字、接收對象、前往位置及啟用／停用設定保持原值。
- [ ] 原有新增、刪除、照片放大、工作回報、庫房、線材與電鍍操作正常。
