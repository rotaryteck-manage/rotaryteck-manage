# v41 線材移除照片介面、員工標記補貨

適用已更新到 v40 的網站。解壓後依原資料夾位置覆蓋 GitHub 專案，沿用現有 Cloudflare 部署流程。本包尚未部署正式網站。

- 線材庫存清單、單筆／多筆裁線表單及裁線總覽移除照片欄位、縮圖、上傳與缺照片提醒。
- 線材區匯出改為文字紀錄及庫存 CSV，不再下載照片。
- 可登記裁線的員工可將線捆標記為「需補貨」。只有倉管與主管可改回「足量」。伺服器同步檢查權限。
- 單筆與多筆裁線表單顯示警語：「裁線時若發現線材快用完，請記得將狀態改為『需補貨』。」
- 單筆表單新增需補貨勾選，多筆表格每列亦可勾選；與裁線紀錄一起儲存。未勾選不會清除原有需補貨狀態。
- 補貨名單保留，由倉管、主管巡查後更新。
- 後台權限表單移除線材照片選項。庫房與電鍍照片功能不變。

既有照片、照片關聯與舊紀錄未刪除，仍可由主管在後台匯出全部資料／全部照片備份。修改舊裁線紀錄不會清除舊照片關聯。歷史資料相容與備份讀取機制保留。

驗證：73 項自動測試通過，涵蓋員工標記需補貨、禁止員工改回足量及原有儲存／備份流程。另完成 DOM 測試：照片欄位移除、無照片提醒、單筆／多筆同時標記補貨、修改舊紀錄保留照片關聯、倉管回復足量。Worker 已建置並檢查語法；未在正式資料上操作，未完成真實瀏覽器視覺驗收。
