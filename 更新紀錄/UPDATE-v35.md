# v35 後台刪除、批量刪除與登入介面

接續 v34。解壓縮後依原目錄覆蓋 GitHub 同名檔案，並加入 bulk.js。等待 Cloudflare 部署成功後重新整理。

## 後台管理
- 線材新增單筆刪除；庫房後台列出專案並提供單筆刪除。
- 員工、案件、庫房、電鍍、線材、自訂欄位、頁面與區塊、自訂權限加入批量刪除。
- 點批量刪除後可勾選或全選，顯示已選筆數，再按刪除並確認清單。
- 線材、電鍍採已刪除清單，可勾選還原，照片與歷史紀錄保持原有關聯；庫房沿用原本的已刪除清單。
- 案件、員工刪除沿用既有規則；員工刪除會撤銷存取，不能刪除目前登入者。
- 自訂欄位及頁面／區塊只刪除草稿，發布後才套用前台。已填的自訂欄位資料不清除。
- 內建權限及仍有員工使用的自訂權限不能批量刪除。
- 網站設定、資料備份等不屬於資料清單的操作區不提供整區刪除。

## 登入
- 登入畫面顯示既有公司 LOGO；未設定時使用預設圖示。只開放登入 LOGO 公開讀取，其他照片仍需登入。
- 記住帳號只保存成功登入時勾選的信箱，不保存密碼；取消勾選會清除記住的信箱。
- 密碼可切換顯示／隱藏，預設隱藏。
