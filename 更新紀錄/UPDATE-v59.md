# v59 排程修正與後台紀錄匯出

## 修改項目

- 週表只顯示本週有有效指派的人員。色塊為顯示用途，主管以色塊內「編輯」操作；既有異常的人名不再產生可點的列。
- 每日月曆不在每一天放新增工作紀錄按鈕。上方「新增當日工作紀錄」開啟表單，可選日期，預設台灣今日；有排程或回報的日期可查看紀錄。
- 後台「備份」新增排程與工作紀錄匯出：可複選每週排程、每日工作紀錄、收料、寄出；可選日期範圍（一年內）及 CSV、照片。照片以類型／日期分類，資料加照片會產生 ZIP；單一類型且只有資料時下載 CSV。
- 收料紀錄取自庫房的收料明細；收料照片依照片上傳日篩選。寄出紀錄取自電鍍送鍍的寄出日，相關照片依該寄出日納入。每週排程跨越範圍的項目亦納入。
- 後台員工權限新增「後台：匯出排程、工作紀錄與照片」。既有主管權限設定會自動加入一次，之後可在權限設定調整。授權的非主管會看到獨立「資料／照片匯出」頁，無法進入其他後台設定。
- 現有「複製排程圖片」保留；未新增下載排程圖片按鈕。

## 部署

將壓縮包相對路徑覆蓋在 v58 專案根目錄後執行既有部署流程。保留資料庫與照片儲存，不重設資料。新版後台權限會在員工下一次查詢權限時完成一次性更新。

## 驗證

`npm run build` 和 `npm test` 通過（109 項）。照片 ZIP 採瀏覽器端整理，單次照片總量上限 250 MB；較大的月份請分段匯出。
