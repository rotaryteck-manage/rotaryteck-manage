# v69 排程人員、日期範圍與工作紀錄

## 更新

- 新增／編輯排程時，將完整人員名單放在日期上方，直接勾選姓名。每項工作各有獨立名單與「全選」，因此不同工作仍可安排不同人；後台的人員排序沿用原設定。
- 每日排程的新增／編輯畫面一次載入當天所有已排工作，支援增添工作並整批儲存；已存在的工作保留原紀錄，不會重複新增。改選日期會載入新日期的安排，請先選日期再填寫。當天未指派的人不出現在工作紀錄。
- 每日工作紀錄改為「人員名稱　工作項目(工作內容)」同一列；一個「編輯當日排程」入口可編輯當日全部工作。
- 每週排程色塊依每項工作實際日期分開。日期設為 09/28 至 09/28 時，該工作只佔 09/28 的一格；後續日期的工作各自顯示。複製排程圖片也使用相同的日期範圍。
- 國定假日與週末在每週表格中，日期標題與下方每位人員的對應格都顯示淺紅框及底色。

## 安裝

此包以 v68 為基礎。覆蓋同路徑檔案後重新建置與部署；此次無新增資料庫遷移。

## 核對

`npm run build` 與 `npm test` 通過，共 119 項測試。包含單日工作不延伸至後續日期，以及相鄰日期工作的分格顯示。
