# v56 工作排程更新

新增「工作排程」管理區，含每週歷史排程、每日月曆、工作安排、文字與照片回報；庫房既有收料／領料紀錄在排程日期顯示，新增收／領料仍透過庫房頁完成，確保庫存一致。

權限：每週及每日安排限具有對應權限的主管；收／領料預設主管與倉管；每日回報預設一般員工以上。後台「員工權限」可調整對應勾選。新排程頁文字與顏色可在「全站文字、配色與 LOGO」的「工作排程」分類調整。

國定假日與特殊日期由主管新增並輸入該年度實際日期；週六、週日會自動標示。排程照片單張上限 2 MB。匯出圖片供 LINE 分享。

## 更新順序

1. 將此包內檔案依原路徑覆蓋在目前 v55 專案，保留網站現有資料與環境設定。
2. 先套用 `drizzle/0004_schedule.sql` 資料庫遷移，再發佈 Worker。若使用現有 Wrangler 部署指令，會自動套用遷移。
3. 更新後在後台確認三種內建角色的排程權限；先前自訂過的角色需手動勾選新增的權限。
4. 用主管、倉管、一般員工各驗證一次預期可見和可操作的功能；手機畫面仍需實機檢查。

現有網站與資料不在本包執行時刪除。此包未部署到正式站。
