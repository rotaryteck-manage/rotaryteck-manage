# v83 通知公鑰與安卓工作回報拍照修正

日期：2026-10-01

## 修正內容

- wrangler.jsonc 改用使用者提供的完整 VAPID 公鑰；舊值只有 48 字元、36 bytes，無法建立通知訂閱。
- 建置、後端與前端檢查公鑰格式及 P-256 有效性。錯誤設定改為中文提示，不再直接顯示 applicationServerKey 英文錯誤。
- 通知權限在按鈕點擊流程立即請求，並等待 Service Worker 啟用後才建立訂閱。
- 安卓/iPhone 工作回報的拍照程式改接實際欄位 photo-report80；原本使用舊欄位名稱 photo，導致兩個手機按鈕未出現。
- 「直接拍照」「從相簿選擇」共用原有照片預覽與待上傳清單，不依賴 DataTransfer。取消拍照保留原照片與文字，最多 10 張，刪除後可補照片。
- 保留照片必填、照片大於 800 KB 自動壓縮及既有工作指派/權限檢查；不更動月曆版面或料件流程。
- 更新相關腳本版本參數以避免載入舊檔。

## 部署方式

1. 更新至包含本修正的 GitHub 版本。
2. 沿用建置命令 `node apply-android-v80.mjs && npm run build` 與部署命令 `npm run deploy`。
3. 此次無新增資料庫遷移；不清除舊資料、照片或通知訂閱。
4. VAPID_PRIVATE_KEY 保持現有 Secret，必須與這次公鑰來自同一組。未讀取、修改或提交私鑰。
5. 部署後刷新網站，再按「開啟通知」。安卓工作回報應顯示拍照及相簿兩個入口。

## 驗證與限制

新增回歸測試：完整/截斷/無效曲線公鑰、通知訂閱與綁定流程、建置拒絕截斷金鑰、拍照與相簿共用清單、取消拍照保留照片、10 張上限及刪除後追加。

本次不會向員工發送測試通知。Cloudflare 實際 Secret 配對、正式訂閱與安卓實機相機仍須部署後驗證。
