# v72 更新紀錄

日期：2026-09-29
基礎版本：v71。此包是接續 v71 的差異更新包，尚未部署到正式站。

## 本次四項修改

1. **工作紀錄整排同色**
   - 姓名、【工作項目】與工作內容維持同一排。
   - 取消工作項目的獨立白底框，沿用整排白／淺綠交錯色，刪除鈕底色亦透明。
   - 每週排程及料件類型的既有顏色保留。

2. **請假登記與第三排請假紀錄**
   - 每日排程上方新增一排「請假登記」。主管、倉管具每日排程權限時可登記；一般員工只能查看。
   - 選開始日期時間、結束日期時間、人員及原因。人員可複選，一次登記多人。
   - 原因固定為：事假、病假、公假、其他。
   - 跨日、跨月會在所有涵蓋日期顯示「請假紀錄」，固定於第三排；工作紀錄、工作回報在前，料件紀錄往下排列。没有工作時保留前兩排位置。
   - 點開列出姓名、起訖時間與原因；主管、倉管可編輯與刪除。多人登記為一筆，可編輯人員勾選；刪除前明確提醒會刪除此筆所有人員及整段時間。
   - 使用台灣時間。結束時間不包含在請假範圍內，例如 9/30 13:00 至 10/2 00:00，只顯示在 9/30、10/1。
   - 同一次送出阻擋連點；相同請求重送不重複新增。修改、刪除有版本檢查，避免覆蓋他人更新。
   - 新增／修改／刪除請假會保留每日文字操作紀錄。

3. **庫房已收齊整列配色**
   - 已收齊：淡粉／淺紅交錯。
   - 未收齊：白／淺綠交錯。
   - 整排欄位與固定名稱欄同步使用該排底色；收領料輸入框保留可辨識的輸入樣式。
   - 以原有「本次已備 ≥ 總需求量」判斷，領料造成庫存減少不會誤改為未收齊。舊資料沿用原已收量判斷。
   - 篩選後仍按可見項目交錯顯色。

4. **收料時間、領料時間欄位**
   - 縮窄名稱、規格及數量欄，最右新增兩欄；手機或較窄視窗可橫向捲動。
   - 各料件預設顯示「－」。主管具庫房管理權限時可點擊選年月日，確認後以小字顯示 YYYY/MM/DD。
   - 再點日期可修改；「清除」需再次確認，成功後恢復「－」。
   - 一般員工與倉管只讀；即使另有庫房管理權限，伺服器也禁止非主管修改日期。
   - 日期是手動標記，不會自動改變收／領料數量，也不會自動清除；仍保存在該料件資料中，隨既有備份與還原保留。
   - 儲存日期保留尚未送出的收領料草稿與視窗捲動位置；沿用原雲端衝突檢查與操作紀錄。

## 套用方式

1. 先保留目前 v71 專案與資料備份。
2. 將更新包所有內容覆蓋到 v71 專案根目錄，保留環境設定、資料庫與照片儲存空間。
3. 沿用原 `npm run deploy` 流程，會建置、套用 migration，再部署。新 migration 為 `drizzle/0011_leave72.sql`。
4. 包內已附重新建置的 `dist/server/index.js`；自行重新建置時，必須一併覆蓋 `build.mjs`、新 v72 前端檔案與修改過的 worker 原始碼。
5. 部署後重新整理網站，依四項修改核對。請假資料表使用 IF NOT EXISTS，不清除舊資料，服務亦支援按需建立資料表。

收料／領料日期存於原有庫房資料；請假使用獨立資料表，不會混入工作排程，也不受「重置本週排程」影響。
