# 11.8v 週會介面與通知設定

僅調整週會功能及版本標示，保留其他通知設定、排程資料、權限、介面與原有程序。無新增資料庫遷移；沿用週會設定的 JSON 欄位，舊設定讀取時補上新欄位預設，保留既有標題、內文與版面文字。

## 本次修改

1. 分頁固定為：每日排程 → 每週排程 → 週會紀錄 → 文字記錄。保留原文字記錄權限，在週會頁也能直接開啟。
2. 週會頁沿用工作排程的標題、留白與分頁排版，調整列表及新增按鈕留白。
3. 紀錄框標題、存檔、關閉按鈕增加邊距；存檔按鈕仍固定在框頂端。
4. @ 選人使用方向鍵時，選取項目會自動捲入可見範圍；Enter 選人，Esc 關閉。
5. 地點提供工作區、會議室、其他；預設工作區。選其他時同格改為文字輸入，既有自訂地點可原樣編輯。
6. 僅週會內容與建議欄自動轉換 >> 為 →、<< 為 ←，保留游標，中文輸入組字結束後才轉換。
7. 週會紀錄通知出現在系統通知規則清單；提供預覽、編輯、啟用/停用、刪除。上方「週會紀錄通知設定」緊接「匯出通知紀錄」，兩處共用設定。新增通知類型也可選週會紀錄即時通知。
8. 通知可設定分類、名稱、標題、內容與變數。接收對象預設所有啟用帳號（包含未出席者），也可指定多位。點擊位置固定開啟該則週會紀錄。
9. 官網版本顯示更新為 11.8v。

## 程序邏輯

- 系統通知清單讀取既有週會設定，增加一張週會規則卡片；不修改其他通知規則陣列或排程檢查。
- 首次存檔依當時設定篩選啟用帳號，將會議、操作紀錄、個人鈴鐺通知與接收人待送事件一起儲存。
- 每位接收者各一則，通知網址帶該份週會 ID；使用既有獨立推送與失敗重試程序，成功裝置不重送。
- 編輯、重複存檔、重新啟用、刪除後重建規則均不為舊會議新增通知；停用期間新增的會議不補發。接收名單在首次儲存时固定，後續人員異動不補送。
- 刪除通知規則只停用週會通知並隱藏其卡片，會議仍保留。可從上方入口或新增通知重新設定。
- 設定與紀錄仍使用版本衝突檢查；錯誤保留輸入，重新開啟可讀取最新設定。

## 已完成驗證

- 完整自動測試 347 項通過，包含指定接收者、舊設定相容、錯誤設定拒絕、刪除/重建不補發，以及原有其他功能回歸。
- 建置及 Wrangler 部署乾跑檢查通過。
- 本機測試資料：手機 390px、電腦 1280px，驗證分頁順序、地點、箭頭轉換/中文組字、鍵盤選人自動捲動、長內容/固定存檔、編輯、通知設定互通與精準路由。
- 本次不在正式環境新增測試會議或發送真人通知；正式手機送達需使用下列人工項目驗收。

## 檢查項目（手机、電腦）

1. 名稱／職位旁顯示 11.8v。
2. 每日、每週與週會頁分頁均為「每日排程 → 每週排程 → 週會紀錄 → 文字記錄」，且文字記錄可開啟。
3. 週會列表、標題與新增按鈕留白正常；紀錄框按鈕不貼邊，捲動長筆記時存檔仍可見。
4. 輸入 @，方向鍵往下超過可見名單，確認選取列自動出現；Enter 變成（人名），Esc 收起。
5. 地點可選工作區、會議室；選其他可直接輸入。存檔後重新開啟，地點不遺失。
6. 內容、建議輸入 >>、<< 轉成箭頭，其他欄位及其他區域不受影響。
7. 後台上方設定入口在匯出通知紀錄後；通知規則清單能找到週會卡片，兩處修改互相一致。
8. 自動接收模式新增一份測試週會，確認啟用帳號包含未出席者收到同一份紀錄通知；點通知開啟該則內容。
9. 指定多位接收者新增另一份週會，只有勾選的啟用人員收到通知。預覽只顯示內容，不會發送。
10. 編輯該份週會再存檔不重發；停用期間新增再啟用不補发；刪除後重新建立通知規則不補發舊會議。
11. 每日工作、工作回報、線材、電鍍等既有設定及其他頁面保持原樣。
