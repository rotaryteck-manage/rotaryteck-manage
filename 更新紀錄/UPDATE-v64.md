# v64 每人合併成單一工作色塊

## 更新

- 修正每週排程同一人仍顯示兩條色塊的問題：同一人整週只有一條色塊，色塊內依原工作順序逐行顯示各項工作，例如「FAA(組裝)」在上、「廠內布置(監督)」在下。
- 每項工作右側各有一顆小型「編輯」按鈕，可直接修改對應的工作。若同一人各工作的日期不同，該行會標示自己的日期，避免單一色塊讓日期產生歧義。
- 複製每週排程圖片同樣合併成單一色塊，並保留工作順序。

## 安裝

此壓縮包為相對於 v63 的增量更新。覆蓋相同路徑後重新建置、部署；無新增資料庫遷移。v63 的 `0007_schedule_work_order.sql` 仍需已套用。

## 核對

`npm run build`、`npm test` 通過，共 113 項測試，包含確認同一人兩項工作只產生一條色塊、兩行工作與各自的編輯按鈕。
