# v28 電鍍出入貨總表、焊接人員、匯出權限

適用 v27。解壓後依原路徑覆蓋至 GitHub，等待 Cloudflare 部署成功，所有使用者重新整理網頁。

- 電鍍管理上方新增出入貨紀錄表。每次送鍍一列，顯示案名、次數、廠商、寄出日、回貨日、治具／環片總量、狀態、焊接人員。
- 全部／送鍍中／已完成篩選含筆數，另可搜尋案名。未完成優先，同類寄出日期由新到舊。小字緊湊、固定表頭、隔列底色；手機橫向滑動。
- 點紀錄開啟原送鍍表單，可返回總表。一般員工唯讀，倉管／主管可登記。
- 移除品檢與備註輸入，歷史值仍保留於資料與歷史匯出中。未填回貨日＝送鍍中；已填＝已完成。
- 日期下方顯示自動狀態、焊接人員。每次開啟表單即重新讀取員工 ID 與姓名，包含所有角色及停用人員，不回傳員工信箱。刪除員工後不再供新紀錄選擇，舊紀錄保留原姓名。再次送鍍需重新選擇焊接人員。
- 所有系統匯出（含 JSON、Excel、CSV、照片 ZIP、BOM 範本）限制主管，下載前重新向後端確認角色；帶有匯出標記的照片列表及檔案請求也僅主管可取用。一般照片查看與倉管上傳／刪除不變。
- 員工若儲存失敗可重試；未儲存 JSON 下載也限制主管。
- 可以查看資料的人仍能手動複製可見文字或另存可見圖片；權限控制的是系統提供的匯出功能。
- 文字設定沿用後台電鍍管理，新增總表、狀態、焊接人員、篩選和匯出表格文字可調整。

驗證：53 項測試通過，另完成模擬瀏覽器總表篩選、開啟明細、焊接人員保存、歷史姓名保留、倉管／一般員工隱藏匯出，以及既有電鍍及照片流程。尚未部署正式網站。
