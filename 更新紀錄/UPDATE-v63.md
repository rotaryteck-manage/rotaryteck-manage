# v63 每人單列、工作順序與排程後台

## 更新

- 每週排程中，同一位人員只顯示一列；該人員的多項工作在同一列依「工作 1、工作 2」順序由上往下排列，不再重複開人員列。多位人員共同負責的工作仍會在各自的人員列顯示。
- 工作項目與工作內容改顯示為「FAA(製作)」「廠內布置(監督)」；每日月曆、當日紀錄和每週複製圖片同樣使用此格式。仍可點編輯修改各項工作。
- 新增工作順序欄位；舊排程依原始建立順序補齊，避免舊畫面按標題或亂數編號重新排序。後續新增、修改、複製排程均保留順序。
- 新增後台獨立「工作排程」分頁，內有「修改排程文字／按鈕」及「調整人員名單順序」。文字設定依排程頁面、排程表單、每週備註、每日料件、工作回報分區，未設定沿用原字；可補充其他原文字。不修改員工姓名或已填工作資料。
- 「人員（可複選）」清單和左右兩個輸入框同高，名單在框內下捲勾選；原本後台的人員排序設定仍為共用順序。

## 安裝

本壓縮包為相對於 v62 的增量更新。覆蓋相同路徑，先執行 `drizzle/0007_schedule_work_order.sql`，再依原流程建置並部署。遷移保留現有排程與回報。

## 核對

`npm run build`、`npm test` 通過，共 113 項測試；涵蓋舊工作順序還原、多工作同一人排序、文字設定格式與原有功能。
