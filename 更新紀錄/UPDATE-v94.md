# v94 更新紀錄

## 線材補貨

- 新建立的補貨紀錄固定排在最上方。
- 勾選「已訂購／已入庫」只補上處理時間，不會改變原本排序。
- 補貨名單上方新增「刪除補貨紀錄」，可勾選多筆後一次刪除；不在每一列放刪除鈕。
- 新增需補貨本身不發通知，只有符合逾期天數與時間的規則才通知。

## 通知

- 線材與電鍍提醒改成同一規則、同一人、同一紀錄、同一天最多自動發送一次。
- 修改規則時間、紀錄日期、內容或接收名單，不會讓當天已發送的同一紀錄重發；隔日再依重複間隔判斷。
- 通知規則在當日發送時間以前修改，當日仍可照新設定發送；發送時間以後修改，當日不追補。
- 後台新增「立即檢查通知」及今日狀態，方便不用等待五分鐘排程就能驗證正式規則。
- 點擊目的地增加「線材補貨待處理名單／電鍍總覽／電鍍待處理名單」。自動逐筆提醒仍可直接進入指定紀錄。
- 修正通知深層連結可能一直等待、無法自動開啟指定畫面的問題。

## 儲存與刪除

- 全站刪除在確認後先從畫面移除；若雲端儲存失敗，會由已確認的雲端版本復原。
- 庫房、電鍍與線材的大型資料驗證改用索引查找，降低資料量增加後的運算量及 Worker 503 風險。
- 保留現有「只傳送實際變更紀錄」的局部儲存方式；照片仍使用獨立上傳流程。

## 驗證

- 自動測試 248 項全部通過。
- 正式建置及 JavaScript 語法檢查通過。
