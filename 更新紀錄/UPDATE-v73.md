# v73 更新紀錄

日期：2026-09-29
基礎版本：v72。此包接續 v72 覆蓋更新，尚未部署到正式站。

## 更新內容

1. **複製上週去除重複**
   - 複製前逐人比對工作，來源即使同一安排有四筆，也只複製每人的一份。
   - 本週已存在的相同人員工作不再新增；多人共同安排若只有部分人重複，只補缺少的人。
   - 保留原本的處理中視窗、阻擋連點、同週完成標記與交易失敗回滾。
   - 比對包含日期起訖、工作項目、工作內容、顏色及備註。不同日期、內容、顏色或備註保留，不只依標題判斷。

2. **整理既有重複排程**
   - 每週上方新增主管專用「整理重複排程」。
   - 先顯示預計移除的工作筆數、重複人員指派數與清單，按「確認整理」才寫入。
   - 保留每人的一份安排及所有工作回報；多人安排只移除重複人員，其他人保留。
   - 僅整理起訖日期完整落在目前選定週內的工作；跨出該週的工作不更動。其他週、每日排程、請假不受影響。
   - 預覽後若排程已被他人改動，拒絕舊預覽；整批處理有交易保護並留下文字紀錄。
   - 部署不會自動刪除舊重複資料，需要主管自行預覽並確認。

3. **編輯、刪除位置**
   - 每週工作色塊底部左右並排，兩個按鈕同大小。
   - 單日色塊也維持同排，與工作文字分開。

4. **10 格全公司共用常用色**
   - 每週、每日新增或編輯排程都有 10 個小色格，單擊套用。
   - 主管具每週排程設定權限時，可雙擊色格設定顏色，按確定後全公司共用。
   - 另有「設定常用色」入口，方便手機操作。其他有排程編輯權限的人可套用，不能改共用色票。
   - 每次開啟表單讀取最新共用色票；修改色票不會更動已儲存排程的顏色。
   - 多位主管同時修改時有版本檢查，避免直接覆蓋彼此設定。

5. **請假預設時間與按鈕**
   - 新登記預設 08:30 至 17:30；編輯時保留原登記時間。
   - 每日操作按鈕順序為「新增排程｜新增料件｜請假登記｜工作回報」。
   - 桌面四個按鈕同排、同寬高；窄螢幕以兩欄排列，保持可點選大小。

6. **庫房配色依最新指定規則**
   - 已備達到總需求，且現有庫存不小於本次已備：淡粉／淺紅交錯。
   - 現有庫存小於本次已備，或尚未收齊：恢復白／淺綠交錯。
   - 此規則取代 v72「領料後仍維持粉紅」的規則；儲存數量後重新判斷。

7. **庫房直接編輯數量**
   - 移除「更正收料」按鈕。
   - 主管具庫房管理權限時，按「編輯零件資料」即可直接修改「本次已備」與「現有庫存」，再按原本儲存鍵統一儲存。
   - 兩欄各自修正，不自動連動另一欄；留下修改前後數值及操作人紀錄。
   - 一般員工、倉管維持原收料／領料流程，不顯示直接修正欄位。
   - 同一料件若同時填直接修正及本次收／領料，會提示先存修正，再登記收／領料，避免混淆絕對值與增減量。
   - 本次已備修正不竄改原累計收料；後續正常收料會繼續增加已備。新一輪製作以原流程重新計算備料，撤銷新一輪會還原修正值。

8. **後台設定庫房櫃、庫房層**
   - 管理後台 → 庫房 →「設定庫房櫃／庫房層選單」。
   - 每行一個完整名稱，例如 A櫃、備料櫃、1層、10層，可新增、修改、刪除與調整順序。
   - 主管儲存後全公司共用，既有案件與新增案件都使用此選單。
   - 刪除或改名選項不會更改已存案件的位置。舊位置仍可顯示，直到使用者自行改選。
   - 每類至少保留一個選項，禁止空白、重複或過長選項。

9. **預設每日排程**
   - 初次進入及從其他區域返回工作排程時，預設每日排程。
   - 上方順序改為「每日排程｜每週排程｜文字記錄」，文字記錄仍限主管。
   - 在每週畫面切日期或儲存工作時，不會跳回每日。

## 套用與核對

1. 保留目前 v72 專案和資料備份。
2. 將此包所有內容覆蓋到 v72 專案根目錄，保留原環境設定、資料庫與照片。
3. 沿用原 `npm run deploy` 流程，會重新建置、套用 `drizzle/0012_schedule73.sql` 並部署。新資料表也支援按需建立，不清除既有資料。
4. 已附建置完成的 `dist/server/index.js`。自行建置時須一併套用 `build.mjs`、所有附帶前端與 worker 原始碼。
5. 部署後重新整理。針對已重複的週別，先選到該週，點「整理重複排程」核對清單，再確認整理。
