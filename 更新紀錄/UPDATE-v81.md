# v81 同人多工作與手機拍照

## 更新內容
- 每日排程編輯：相同已選人員的工作放在同一個框，框內「追加工作」沿用人員；最下方「新增工作區塊」建立獨立區塊。
- 同一框變更人員，框內所有工作同步套用；工作仍各自保留 ID、內容、刪除與權限檢查。
- 工作紀錄：同一天每人一個框，姓名只顯示一次，每項仍可單獨刪除。多人共用同一項工作時，仍沿用原本的刪除確認，提醒所有指派人員會同步移除。
- 手機工作回報加入「直接拍照」「從相簿選擇」，拍照選圖後預覽，儲存時上傳；取消拍照不清除已填內容與原照片。
- 電腦保留選擇檔案與貼上圖片。

## 上傳 GitHub
將本包解壓，將 build.mjs、dist 資料夾中的兩個新檔、更新紀錄資料夾上傳到現有專案根目錄，提交到 main 即可。
沿用目前 Cloudflare 建置命令：node apply-android-v80.mjs && npm run build
部署命令仍是 npm run deploy。保留現有 apply-android-v80.mjs。
本包沒有 index.html、mobile-v78.css、schedule-v67.js、worker/server.mjs，不會覆蓋已手動修改的手機月曆。
build.mjs 只新增兩個資源，並在建置產出的頁面載入；原始 dist/index.html 不會被改寫。

## 驗證與限制
已完成建置、Worker 語法檢查與瀏覽器操作：既有同人工作合框、框內追加沿用人員、獨立新增、單項刪除、人員同步、儲存項目與刪除清單、紀錄分組、手機相機檔案接入、取消後保留輸入。
相機以瀏覽器檔案輸入模擬驗證，尚未在安卓/iPhone 實機拍照，也尚未部署。
相機開啟方式仍由手機系統與瀏覽器決定；若不支援直接呼叫相機，可使用相簿選擇。
