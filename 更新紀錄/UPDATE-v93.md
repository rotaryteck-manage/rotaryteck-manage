# Rotaryteck Manage v93

日期：2026-10-03  
基礎版本：v92（此差異包同時包含尚未正式交付的 v92.1 可靠性修正）

## 本次修正

1. 線材與電鍍通知改為每筆資料使用固定識別碼。新增一筆資料時，不再把全部舊資料重新通知。
2. 同一次檢查發現多筆新到期資料時，每台裝置只發一則合併推播；後續檢查會依每筆收件憑證防重。
3. 每筆線材／電鍍資料各自計算逾期天數，不再把最久的一筆天數套用到全部資料。
4. 移除會造成 `LIKE or GLOB pattern too complex` 的舊式模糊比對；補發失敗改顯示中文，失敗不占通知額度。
5. 線材通知會開啟待處理補貨名單並定位該筆；名單同時顯示「需補貨」及「已訂購」。
6. 電鍍通知會直接開啟該筆送鍍紀錄；資料已處理或刪除時，改開啟電鍍總覽並提示。
7. 測試通知紀錄改成「一次測試一區」，其下收納各裝置的成功／失敗結果。
8. 電鍍人員選單統一以穩定人員編號比對，避免排序或重新載入後畫面名稱與實際值不一致。
9. 線材大量資料驗證改用索引，避免逐筆重掃全表造成 Worker 資源超限及 503。
10. 保留 v92.1 的通知額度、防重收件憑證、規則修改後當日抑制、補發確認及存檔錯誤保護。

## 部署

將差異包內容覆蓋至目前 v92 專案根目錄後執行：

```bash
npm run deploy
```

部署完成後，手機網站或主畫面捷徑請完全關閉再重開一次。
