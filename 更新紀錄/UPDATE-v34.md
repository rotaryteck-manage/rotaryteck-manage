# v34 照片載入與按鈕統一

接續 v33：解壓縮後按原目錄覆蓋 GitHub 同名檔案，並加入新檔案。等 Cloudflare 部署成功，再重新整理網站。

- 新上傳的庫房、電鍍、線材及 LOGO 圖片自動另外產生縮圖（最長邊 360 px，上限 96 KB）。原本儲存的大圖保持供查看與匯出。
- 線材列表與 LOGO 優先載入縮圖；庫房及電鍍原有照片連結維持點擊才載入。
- 圖片在本頁面記憶體暫存，重複開啟可以重用；同時最多讀取三張。登出或離開頁面會清除，未使用公開圖片快取。
- 舊照片缺少縮圖時自動使用原圖，所以第一次開啟仍可能較慢，不必重新上傳。
- 對調「新增裁線紀錄」與「新增線捆」位置。
- 前後台文字操作按鈕统一字級、高度、內距，同組按鈕依最長文字對齊寬度，連結型按鈕也套用。圖片縮圖、卡片與關閉圖示保留專用尺寸。
- 主管匯出仍使用大圖，縮圖不列入照片清單或 ZIP。

新增 photos.js、controls.css 已加入建置清單。
