# v62 排程輸入框與人員清單排序

## 更新

- 每筆工作的「工作項目」「工作內容」輸入框固定為相同高度，不再跟著人員欄撐高；欄位與間距縮小，使表單更整齊。
- 人員欄限制高度，名單在欄內向下捲動選取；手機畫面改為單欄排列，仍可捲動勾選。
- 排程名單依後台「員工名單 → 調整排序」設定顯示；停用員工不列入新增工作的選擇，人員排序變更後重新開啟排程即可看到結果。
- 修正獨立新增的每週備註在複製排程圖片中未顯示的問題。

## 安裝

此壓縮包為相對於 v61 的增量更新。覆蓋相同路徑後，依原流程重新建置、部署。不需要新增資料庫遷移。

## 核對

`npm run build` 和 `npm test` 通過，共 110 項測試。新增驗證後台員工排序會套用到排程人員清單。
