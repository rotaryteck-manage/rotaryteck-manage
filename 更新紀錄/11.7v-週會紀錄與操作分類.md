# 11.7v 週會紀錄與操作分類

本版以 11.6v 為基礎，只新增週會紀錄、週會設定與資訊庫分類。既有頁面尺寸、字型、按鈕、排程與通知設定不重設。右上角版本更新為 11.7v。

## 操作位置

- 工作排程 → 週會紀錄。全公司啟用帳號可查看；主管可新增、修改及刪除。
- 後台 → 工作排程 → 週會紀錄文字設定。
- 後台 → 系統通知 → 週會紀錄通知設定。
- 資訊庫 → 每日排程／每週排程／週會紀錄。

## 會議內容

開會日期、時間、地點，以及可複選的出席人員。下方為「筆記／內容／建議」三欄；筆記編號自動排序，內容欄最大。輸入 @ 搜尋姓名，選取後成為「(姓名)」普通文字，不另發提及通知。同名者選單附編號。每份最多 100 列，內容每列 4000 字、建議 2000 字；至少一列內容非空白才能存檔，完全空白列不儲存。長文字會換行並讓同列框齊高。

新增筆記建立下一列；每列有小型移除按鈕。有內容的列移除前確認。存檔按鈕位於框上方，内容只在框內捲動。存檔後可再開啟編輯，框內小字顯示最後編輯日期、時間、人員。清單每筆一條細列「YYYY/MM/DD - 週會紀錄」，依開會日期由新到舊；同日依時間與建立時間排序。

## 儲存與通知程序

1. 後端驗證啟用帳號、主管身分、來源、必填欄位、出席名單及版本。
2. 一次資料庫交易儲存會議、操作歷程、首次通知接收名單、鈴鐺紀錄及操作編號。
3. 首次存檔、通知啟用時，固定當下所有啟用帳號，不以出席名單限制接收者；停用帳號不列入。
4. 成功提交後立即啟動背景推播，每位接收者使用獨立執行，避免全員推播和存檔共用免費方案 CPU／查詢額度。採簽章、短時效的內部發送連結，不公開秘密金鑰、不新增付費服務。
5. 每個帳號首次背景執行最多處理兩個尚未送出的裝置。一般手機與電腦兩台會一起處理；裝置更多、額度不足或失敗者，保留任務供每三分鐘排程重試。已成功的裝置不重送；手機系統實際顯示時間仍需實機驗收。
6. 後續編輯及再次存檔只更新內容、最後編輯資訊與操作歷程，不新增通知。停用期間建立的會議不在重啟通知時補發。新加入的帳號不補收到既有會議通知。
7. 既有全站通知額度、裝置訂閱及個人通知停用設定沿用。每個啟用帳號都建立鈴鐺紀錄；裝置推播仍需該帳號／裝置已開啟通知。
8. 開啟鈴鐺或手機通知時，直接開指定紀錄；冷啟動等待登入資料就緒，成功開啟才清除目標參數。已刪除紀錄顯示已刪除或不存在。

儲存使用固定操作編號與版本防止連點、網路重試產生重複記錄。兩位主管修改同一份資料時，較舊版本收到衝突提示，未存文字仍留在原框；可自行複製後載入最新版。未存修改關閉框或離開頁面會提醒。

## 後台設定

通知開關、標題、內文及本區版面文字均可設定；支援 {會議日期}、{會議時間}、{會議地點}、{記錄人}、{出席人員}、{筆記數}。附預覽及恢復預設，預覽不送真實通知，恢復預設需儲存才生效。這些設定使用獨立資料表，不改既有通知規則。

## 資訊庫

新增每日排程、每週排程與週會紀錄分類；原搜尋、日期、刪除權限及匯出功能沿用。新增分類記錄本版上線後的操作，不回補舊歷程。每日、每週安排的新增、修改、刪除、批次、複製及重置，在原資料交易中追加資訊庫紀錄。週會新增／修改／刪除記錄日期、操作者及前後內容。備份資料表增加週會相關資料，不刪除既有資料。

## 部署

新增遷移 drizzle/0032_meetings117.sql，現有 npm run deploy 在部署前套用。Wrangler 追加 global_fetch_strictly_public，供新週會背景任務呼叫本站獨立發送入口；既有 cron 仍是 */3 * * * * 與每小時的清理。未新增 Worker、付費訂閱或改通知時間。

## 檢查項目

1. 重新整理，確認右上角為 11.7v，其他原有頁面、框框及尺寸維持。
2. 工作排程有週會紀錄分頁；填日期、時間、地點，勾選多位出席者。
3. 內容與建議輸入 @，選取後為 (姓名)；此動作不通知。
4. 新增多列、填長文字，確認手機及電腦欄位齊高，捲到底仍看得到上方存檔。
5. 首次存檔確認後，出席者、未出席的啟用帳號都收到鈴鐺紀錄；已開推播的手機／電腦檢查通知及後台成功狀態。
6. 點通知能直接開啟指定週會。以冷啟動及已登入狀態各測一次。
7. 修改內容再存檔，確認最後編輯資訊更新，沒有新通知。
8. 通知停用後新增一份，再啟用，確認該份不補發；之後新增另一份才通知。
9. 後台修改通知標題、內容與本區文字，先預覽，再儲存並新增會議驗證。不要把測試會議首次存檔誤當預覽，因為會通知全公司。
10. 一般員工可查看但不能編輯或刪除；未存文字關閉有提示；兩位主管同時編輯有衝突提示。
11. 資訊庫三個新分類可篩選、搜尋及匯出；每日／每週正常新增、編輯、刪除也有紀錄。
12. 刪除一份測試會議後，再開舊通知顯示已刪除，不跳錯頁。
