v90.2 驗收步驟

一、部署
1. 使用本包內容覆蓋專案同名檔案。
2. 執行原本的 npm run deploy。
3. 部署程序會先建置，再自動套用 D1 migration，最後部署 Worker。
4. 部署完成後，手機與電腦重新整理網站一次。

二、工作回報時間
1. 開啟工作排程 > 每日排程。
2. 點進今天的「工作紀錄」。
3. 確認工作回報顯示「回報時間：YYYY-MM-DD HH:mm」。
4. 原本畫面顯示 09:22 的紀錄，應顯示為台灣時間 17:22。

三、最後修改時間
1. 編輯一筆既有工作回報文字並儲存。
2. 重新開啟工作紀錄。
3. 確認原始回報時間保持不變，旁邊增加「最後修改」。
4. 重新上傳該筆工作照片後再開啟，最後修改時間應再次更新。

四、17:25 工作回報提醒
1. 在每日排程安排一筆今天的工作給測試人員。
2. 測試人員不要先送出工作回報。
3. 到 17:25 後等待最多 5 分鐘，應收到自己的待回報工作提醒。
4. 若已在 17:25 前完成回報，系統不應再提醒。
5. 每週排程不會觸發這項通知。

五、v90.1 合併驗收
1. 手機每週排程底部顯示：新增排程、複製上週、新增備註、其他功能。
2. 每個每週工作區塊可獨立選星期、人員與色塊。
3. 點人名可展開管理後台、修改密碼、更換帳號及登出。
4. 過期停班公告不再出現在通知中心或行事曆。

六、國定假日與停班來源
1. 後台通知規則中的停班提醒應顯示「官方公告後立即發送」。
2. 展開「政府國定假日資料狀態」，可查看最後檢查時間及明日是否為國定假日。
3. 展開「官方停班資料狀態」，可查看左營區目前狀態與適用日期。
4. 編輯國定假日或停班規則時，「依功能自動判斷」應保持選取，不可自行跳成指定人員。
