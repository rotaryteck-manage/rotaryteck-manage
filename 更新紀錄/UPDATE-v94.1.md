# v94.1 修正版

## 修正內容

- 修正補貨名單被舊版程式覆蓋，造成 v94 的刪除按鈕沒有顯示。
- 補貨名單上方新增「刪除補貨紀錄」，勾選後可批次刪除；線材、照片與裁線歷史保留。
- 新增補貨固定依原始登記時間由新到舊排列，後續更新訂購或入庫狀態不改變順序。
- 修正手機 PWA 點擊線材、電鍍通知只到管理區，沒有進入指定名單或紀錄。
- 通知跳轉支援首次開啟、既有視窗、切回前景、網址變更與重複點擊。
- 全站儲存時顯示「正在上傳雲端，請勿重複操作」，成功後短暫顯示「已儲存到雲端」。
- 暫時性 429／502／503／504 儲存錯誤會使用相同請求自動重試一次，不會重複建立資料。
- 一般修改改為後端只讀取相關紀錄與必要關聯資料，避免每筆操作都重建全部雲端資料。
- 新增、刪除、排序、改名或改編號等需要全區比對的操作，仍保留完整資料驗證。
- 雲端狀態列顯示 v94.1，方便確認手機或電腦是否已載入新版本。

## 部署後先確認

1. 頁面上方雲端狀態可看到 `v94.1`。
2. 線材管理 → 補貨名單，上方可看到「刪除補貨紀錄」。
3. 後台發送線材待補貨測試通知，點擊後直接開啟補貨名單。
4. 後台發送電鍍總覽／待處理／指定紀錄測試通知，點擊後進入對應畫面。
5. 修改庫房、電鍍、線材資料時，畫面顯示「正在上傳雲端」，完成後顯示「已儲存到雲端」。
