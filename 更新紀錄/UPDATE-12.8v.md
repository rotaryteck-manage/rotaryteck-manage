# 12.8v：品檢已刪除案件列的左右間距

本次僅替品檢報告首頁「已刪除案件」區塊增加 18px 左右內距，與既有 `.plating-head`、`.plating-grid` 的左右間距一致，避免展開箭頭與文字貼住外框。

樣式只套用 `.qc-workspace124 > [data-qc-deleted]:not(:empty)`。沒有更動文字內容、字型、字級、上下面距、外框、通知、刪除／復原權限或其他功能。沒有刪除權限而未顯示此區塊時不增加空白。

版本顯示更新至 12.8v；該 CSS 的載入版本同步更新。後端與資料庫均無修改。

驗證：既有 422 項自動測試通過、建置通過。此為單一樣式調整，沒有新增會複製實作的測試。
