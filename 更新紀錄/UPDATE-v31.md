# v31 排序與權限按鈕

適用 v30。解壓後依原路徑覆蓋 GitHub，等待 Cloudflare 部署成功，所有人重新整理網站。只含變更檔案，既有資料保留。

- 電鍍格子加入上下左右移動，保留拖曳把手。上下依螢幕欄數交換位置，邊界按鈕停用。
- 新增線捆只需填寫顏色，編號自動接續目前最大數字＋1；既有線捆資料與編號保留。
- 線材內容上方新增「調整排序」。修改某項要排第幾位，其他項目自動順移，儲存後更新列表。排序數字與線捆實體編號分開，避免重新排序造成現場標籤對不上。
- 員工列表移除上下箭頭，改成上方「調整排序」按鈕，使用相同數字排序方式。焊接人員選單沿用員工順序。
- 權限設定改成橫向按鈕：主管、倉管、一般員工，以及各自訂權限。點按鈕單獨設定名稱與可操作內容；新增後自動建立按鈕。
- 「調整按鈕位置」顯示左右箭頭，順序保存到雲端。
- 內建權限不可刪除；自訂權限仍有員工使用時不可刪除。
- 管理後台與匯出固定只有主管。補貨狀態固定主管／倉管。主管保留管理設定及完整備份能力，其他管理操作依勾選內容由伺服器檢查。
- 勾選操作權限會自動勾選該區查看；裁線登記會連帶勾選照片上傳。
- 權限變更對伺服器操作立即生效，使用者重新整理後更新畫面。

驗證：62 項自動測試通過；模擬瀏覽器串接後端確認自動編號、線捆數字排序、員工數字排序、電鍍上下移動及新增權限按鈕。尚未部署正式網站。
