# v67 每日排程與全站照片上傳

## 每日排程

- 每日月曆格加高，排程建立後顯示淺紅色「工作紀錄」與「工作回報」兩行入口；就算沒人回報，也可以打開空的回報聊天室。
- 工作紀錄依人員分組，工作以白色、淺綠色交錯條列。既有「新增排程」可在一次儲存中編列多人、多項工作。
- 工作回報以姓名框代替頭像，右側顯示文字、照片及時間。回報人只可選當天指派給自己的工作，進度仍手動輸入。新回報必須附照片，照片與文字一起儲存；上傳失敗時不會留下只有文字的回報。
- 料件紀錄顯示登記人，收料、出貨、送貨分別以淺綠、淺藍、淺紫區分。新增或編輯料件可選填收據照片與料件照片；打開「料件紀錄」直接看到圖片，照片也納入後台匯出。

## 全站照片

- 全站照片上傳超過 800 KB 時在瀏覽器自動壓縮至 800 KB 內，包含原有的收據、電鍍、線材、LOGO、手機圖示，以及新的工作回報與料件照片。較小的原始照片直接使用。
- 新上傳照片的後端也檢查 800 KB 上限；既有照片保持原樣，不重新壓縮。

## 安裝

此壓縮包為相對於 v66 的增量更新。**先套用 `drizzle/0008_schedule_material_photos.sql`，再用同路徑檔案覆蓋並重新建置、部署。**

## 核對

`npm run build`、`npm test` 通過，共 118 項測試。測試涵蓋無照片回報攔截、照片失敗不殘留紀錄、料件兩張照片的儲存與匯出，以及 800 KB 壓縮流程。
