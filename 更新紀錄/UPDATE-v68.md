# v68 每日月曆緊湊顯示與單一料件照片

## 更新

- 每日月曆格的文字、間距和按鈕縮小；一格可顯示至少七行內容，更多紀錄時格子會繼續增高。工作紀錄、工作回報仍維持淺紅色入口。
- 新增料件時增加「案件名稱」，可從現有案件名稱提示選擇，也可以手動輸入。月曆內每筆料件只顯示案件名稱；點該名稱才看到收料／出貨／送貨、料件名稱、數量、登記人與照片。
- 料件照片上傳區只保留一個共用欄位，可上傳收據或料件照片；超過 800 KB 仍自動壓縮。v67 已存的兩類照片保留，進入紀錄仍可查看，重新編輯時只需使用單一欄位。
- 舊料件紀錄原本沒有案件名稱，在月曆先標為「未指定案件」；編輯該筆時補填案件名稱即可。

## 安裝

此壓縮包為相對於 v67 的增量更新。**先套用 `drizzle/0009_schedule_material_project.sql`，再覆蓋同路徑檔案、重新建置與部署。**v67 的 `0008_schedule_material_photos.sql` 仍需先套用。

## 核對

`npm run build`、`npm test` 通過，共 118 項測試；包含同一天七筆料件只顯示案件名稱、單一照片上傳及既有兩張照片相容性。
