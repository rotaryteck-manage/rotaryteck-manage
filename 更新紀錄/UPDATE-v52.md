# v52 手機主畫面 LOGO

套用於 v51。覆蓋 ZIP 同路徑檔案後重新部署；尚未代為部署。

- 加入手機主畫面資訊，桌面名稱為「擎正管理」。
- iPhone 使用 apple-touch-icon；Android 使用網頁 manifest 圖示。
- 圖示沿用目前公司 LOGO 的原圖，不需要登入即可讀取；不公開其他業務資料。
- 之後在後台上傳 LOGO 時，自動產生 512×512 PNG，白底留白、保持比例，不裁切。
- 已有 LOGO 可直接使用。若原圖太長或不是正方形，請在後台重新上傳一次同張 LOGO，產生適用手機的正方形版本。
- 部署後，用手機瀏覽器重新開啟網站，再加入主畫面。若舊捷徑仍顯示舊圖示，移除捷徑後重新加入；圖示快取可能需要數分鐘。
- 儲存速度優化仍未實作，依使用者指示維持現狀。

既有 101 項測試及新增 3 項圖示測試通過，Worker 建置與語法檢查通過。未使用實體 iPhone／Android 驗證。
