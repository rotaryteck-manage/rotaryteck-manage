# v40 線材快捷操作、補貨名單、多筆裁線與選填照片

適用已更新到 v39 的網站。解壓後按原資料夾位置覆蓋 GitHub 檔案，再由現有 Cloudflare 流程部署。本包尚未部署到正式網站。

## 線材首頁
- 上方操作按鈕縮為統一 132 × 34 px，依畫面寬度換行。
- 新增「新增裁線紀錄」捷徑，直接開啟多筆輸入表格。
- 新增「補貨名單」：列出需補貨線材、線捆編號與顏色；倉管、主管可直接調整補貨狀態。改為足量後從此名單移除，線捆本身仍保留。一般員工可查看名單。

## 多筆裁線
- 預設 5 列，可按「再增加 5 列」。
- 每列選擇線材／線捆編號／顏色，填每條長度 cm、條數，顯示總長度；照片選填。
- 可以在同批填不同線材、不同顏色與不同長度；全空白列略過。
- 所有列驗證及照片上傳完成後一次儲存。有任何已填列不完整或上傳失敗，該批裁線紀錄不會部分提交。每筆紀錄分別綁定人員、時間與線捆。
- 各線材的文字紀錄也各自記錄對應裁線操作。

## 照片
- 單筆與多筆新增均不再強制附照片。
- 缺照片時跳出提醒，確認後仍能儲存；取消則保留表單輸入。
- 無照片的紀錄顯示「尚無照片」。有修改及照片上傳權限者，可從該筆紀錄的「修改」補上照片。
- 後台「裁線登記」與「上傳照片」權限可獨立設定；補貨狀態仍限倉管、主管，匯出仍限主管。
