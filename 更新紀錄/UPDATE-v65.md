# v65 每人只保留一個編輯按鈕

## 更新

- 每週排程同一人的工作維持單一色塊，工作一、工作二依編列順序上下排列；移除工作之間的分隔線。
- 每人色塊最右側只保留一個小型「編輯」按鈕。點擊後在同一視窗修改該人的全部工作，也可新增或移除工作，最後一次儲存。
- 同一項工作若同時指派給其他人，編輯視窗會提示修改或移除也會影響其他人。工作與刪除動作一起送出；遇到過期版本，整組不儲存。

## 安裝

此壓縮包為相對於 v64 的增量更新。覆蓋相同路徑後重新建置、部署；無新增資料庫遷移。須先安裝 v63 的 `0007_schedule_work_order.sql`。

## 核對

`npm run build`、`npm test` 通過，共 114 項測試，包含一人一條色塊、一個編輯按鈕，以及整組編輯與刪除時的版本檢查。
