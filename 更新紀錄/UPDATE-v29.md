# v29 線材管理與自訂權限

適用已更新至 v28 的網站。此 ZIP 只包含相較 v28 有變更及新增的檔案。

## 更新方式
1. 將 ZIP 解壓縮，依原本資料夾路徑上傳並覆蓋 GitHub 專案中的對應檔案。
2. 等候 Cloudflare 部署成功。此包已包含建置完成的 dist/server/index.js；原本使用自動建置也可繼續使用。
3. 所有人重新整理網站。上方應出現「線材管理」，後台也會出現獨立線材管理按鈕。

既有案件、庫房、電鍍資料與帳號保留。新設定資料表會自動建立，不需手動貼 SQL。此版本新增線材儲存類型，開始使用後請勿直接退回 v28 或更早的程式。

## 操作
- 建立線材只輸入 AWG26；按鈕顯示 AWG26_庫存。可左右排序。
- 進入線材後新增線捆，填寫編號及顏色。預設足量，倉管或主管可直接在列表切換足量／需補貨。
- 點線捆編號新增裁線紀錄。公分為每條長度，條數另填；自動帶入登入人員與時間。
- 新增裁線紀錄必須選擇裁線後照片。超過 2 MB 自動壓縮；上傳完成後照片關聯與紀錄一起提交，失敗不會建立缺照片的裁線紀錄。
- 最新紀錄在上。一般員工與倉管能修改自己的紀錄，主管能修改所有紀錄。修正既有紀錄的長度或條數時，可保留該筆原照片。
- 線捆列表呈現最新照片縮圖，點擊可更換照片。歷史照片保留，原裁線紀錄的照片不會被覆蓋。
- 每個線材項目有收合式文字紀錄。未變更內容不新增文字紀錄。
- 線材紀錄總覽可依線材、關鍵字（編號／顏色／人員）、日期篩選。
- 倉管／主管預設能新增、修改線材與線捆。為保留歷史資料，只有空白線捆及沒有線捆的線材能刪除。

## 匯出與備份
- 主管可匯出單一線捆、單一線材、整區的 ZIP，包含裁線紀錄、線捆庫存狀態、文字紀錄及歷史照片，附照片清單。
- 總覽可匯出目前篩選的 CSV。
- 後台「匯出全部資料」JSON 自動包含線材資料與紀錄；照片仍由「匯出全部照片 ZIP」另外備份，也包含線材照片。
- 大量照片 ZIP 單次以 250 MiB 為上限，可改分線材或線捆匯出。
- 所有匯出維持主管限定，伺服器也會確認權限。

## 後台與權限
- 後台線材管理可修改本區文字、開啟線材管理及維護線材項目。
- 員工清單新增上下排序，焊接人員選單會沿用排序。
- 員工權限區可新增、修改、刪除自訂權限。將員工層級選為一般員工，再指定自訂權限。
- 可設定各區查看、既有管理區管理／收領料／照片操作，以及線材新增、修改、刪除、登記裁線、修改自己的紀錄、上傳照片。
- 既有管理區的「管理」為合併權限，包含新增、修改、刪除及排序；網站設定與員工設定仍主管限定。
- 自訂權限無法取得主管專屬匯出，也無法取得固定屬於倉管／主管的補貨狀態修改權限。
- 已有員工使用的權限不能刪除；先替員工更換權限。員工重新整理套用新介面，伺服器會立即依最新設定檢查操作。

## 儲存與驗證
- 裁線紀錄分筆保存；不同線捆同時登記可合併，同一線捆同時更動仍有版本衝突保護。
- 中斷操作留下的未提交照片，超過 48 小時後在後續上傳時逐批清理；已提交的歷史照片不在清理範圍。
- 建置成功、61 項自動測試通過。另以模擬瀏覽器串接實際後端測試新增線材／線捆、照片必填、裁線保存及修改、角色限制、總覽篩選、後台分頁、文字管理與自訂權限表單。
- 尚未部署到正式 Cloudflare 網站；正式照片儲存與部署狀態需以上傳後實際使用結果為準。
