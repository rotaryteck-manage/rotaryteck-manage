# v51 專案刪除權限與資訊庫分類清除

適用於已套用 v50 的網站。將壓縮檔內同路徑檔案覆蓋至 GitHub，重新部署 Cloudflare Worker；此包尚未部署。

- 前台電鍍、線材：在更多操作加入刪除專案，包含有紀錄的專案，確認後移入 7 天保留區。
- 新增四個獨立刪除專案權限；同時檢查角色與勾選權限。電鍍、線材限倉管或主管；案件、庫房限主管。單筆與批量均受限制，伺服器亦驗證。
- 原本修改／管理權限不再等於可刪除專案。零件、送鍍紀錄、空白線捆的原有管理權限保留。
- 未自訂過的內建角色，預設符合以上刪除規則。已儲存過的權限設定不自動擴權；請主管至後台權限設定勾選新增的各區「刪除專案」，相關使用者重新整理取得設定。
- 後台庫房：名稱為純文字，個別修改按鈕開啟內容，操作仍停留後台。
- 資訊庫更多操作：選擇單一分類後，新增刪除該分類全部紀錄。確認框顯示分類及筆數，涵蓋該分類全部日期與頁面，不受搜尋限制。僅刪除操作紀錄，不刪專案、庫存或照片；限主管且資訊庫已解鎖。
- 原有刪除全部紀錄仍為全分類清除，另有明確確認提示。

驗證：101 項自動測試通過、JavaScript 語法檢查及 Worker 建置通過；本次未執行瀏覽器畫面驗證。
