# v61 排程入口、手動工作與每週備註

## 更新

- 每日排程改為三個等寬操作入口：「新增排程」（主管、倉管）、「新增料件」（主管、倉管）、「工作回報」（一般員工以上）。權限同時由後台權限設定和伺服器檢查；現有倉管內建設定補入每日排程權限。
- 每週與每日新增工作中的「工作項目」「工作內容」改為手動輸入；人員維持複選。保留「新增工作」一次安排多項工作及資料庫批次驗證。
- 工作安排表單移除備註欄。每週頁面新增獨立「新增備註」按鈕，主管可編輯或清空當週備註；有內容時才在每週表格人員下方及複製圖片中顯示醒目的整列備註。每日安排不設備註項目，原有舊備註仍可閱讀。
- 新增料件可登錄日期、收料／出貨／送貨、料件名稱與數量；每日月曆及當日紀錄可查閱，主管／倉管可修改、刪除。新登錄的收料與出送貨分別納入後台既有匯出範圍。
- 移除新增排程時的「設定工作選項」入口；既有選項資料保留，以免影響既有紀錄。

## 安裝

本壓縮包為相對於 v60 的增量更新。覆蓋同路徑檔案，執行 `drizzle/0006_schedule_weekly_notes.sql` 資料庫遷移後，依原流程重新建置並部署。舊排程與工作回報保留。

## 核對

`npm run build` 及 `npm test` 通過；測試包含角色權限、每日排程、料件登錄、每週備註與匯出內容。
