這次更新
1. 已開啟通知的按鈕改為姓名旁的小鈴鐺；鈴鐺顯示未讀數量 1、2、3…，超過 99 顯示 99+。
2. 新增「我的通知」中心：最新通知在最上方，可逐筆開啟、標示已讀或全部標示已讀。
3. 工作排程通知會顯示人員、工作項目與工作內容，例如「黃瑞麟今日工作：FAA（製作）」。不再出現「from 擎正管理」。
4. 點工作通知會直接開啟該日期的工作紀錄；當天沒有內容時保留在該日月曆並提示。
5. 點料件通知會直接開啟該日期、該筆料件紀錄。
6. 主管或倉管新增收料、出貨、送貨後，會立即建立料件通知；預設通知主管／倉管且排除登記人本人。後台可改接收人員、類型及文字。
7. 測試通知新增發送前預覽，可修改接收人員、標題、內容及點擊位置後再發送，並保留「全員」選項。
8. 後台通知紀錄依工作排程、工作回報、線材提醒、電鍍提醒、料件紀錄、系統通知、自訂提醒分類；未知新類型自動歸到「其他」。
9. 後台可自行建立打掃、休息等自訂提醒，設定分類、標題、內容、日期、時間、重複間隔、指定人員及點擊位置，不必再修改程式。
10. 每日／每週新增排程改為一項工作一張卡片；工作項目、工作內容、人員都放在同一卡片內，提供全選、展開／收合、未完成提示。
11. 新增下一項工作時，前一張卡片會自動收合；同一人可出現在多張工作卡片中。
12. 排程視窗底部的「儲存全部排程／取消」保持在底部，避免人員選單展開後蓋住表單。
13. 通知中心資料已納入完整備份。

1. 備份目前正式資料。
2. 解壓「Rotaryteck-v88-差異更新包.zip」。
3. 將解壓後內容放到 GitHub 專案根目錄，依相同路徑覆蓋；不要把外層資料夾一起放入專案。
4. 確認 drizzle/0019_notification_center88.sql 已在 GitHub。
5. 使用原本會執行 npm run deploy 的 Cloudflare 部署流程，確認 D1 migration 成功後再讓新版 Worker 上線。
6. 依「v88-驗收步驟.txt」先測自己的裝置，再測其他人或全員。
