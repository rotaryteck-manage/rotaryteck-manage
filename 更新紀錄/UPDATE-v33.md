# v33 線捆編號與新增裁線紀錄

此更新接續 v32。將 ZIP 解壓縮後，依原目錄覆蓋 GitHub 專案內同名檔案，提交並等待 Cloudflare 部署成功，再重新整理網站。

## 調整內容
- 線捆只需填寫顏色；畫面「編號」按目前順序自動顯示 1、2、3，不可點選。
- 調整排序後，畫面及匯出表格使用新的顯示編號；照片與裁線紀錄仍綁定原本線捆。
- 線材庫存視窗新增「新增裁線紀錄」，選擇線捆後進入填寫。
- 人員下方顯示「線材種類：AWG26｜黑」等綁定資訊。
- 每列保留「裁線紀錄」按鈕查看歷史；新增紀錄仍需上傳照片。
- 所有匯出仍僅主管可操作。

## 相容性
沿用既有資料，不需重新輸入線捆、裁線紀錄或照片。備份 JSON 保留內部識別資料；舊文字紀錄保留當時內容。
