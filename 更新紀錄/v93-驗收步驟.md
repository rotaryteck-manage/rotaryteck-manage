# v93 驗收步驟

1. **先確認版本載入**：部署後關閉所有舊分頁／手機捷徑再重開，後台可正常載入通知規則與裝置狀態。
2. **線材防重**：建立兩筆需補貨資料，設定首次 0 天、重複 0 天；排程跑過後應只收到一則合併通知。五分鐘後不應再收到；再新增第三筆時，只應通知第三筆內容。
3. **電鍍防重**：建立兩筆不同寄出日且尚未回貨的資料；通知內容中的天數應各自正確。新增第三筆不應重列前兩筆。
4. **通知跳轉**：點線材通知，应開啟補貨待處理名單並框出該筆；點電鍍通知，應直接開啟該筆送鍍資料。
5. **已處理資料**：先將通知指向的線材改為足量、電鍍填回貨，再點舊通知；應顯示已處理提示，不可空白或卡住。
6. **測試紀錄**：同一人有兩台裝置時發一次測試；後台只顯示一個測試項目，展開後看到兩台裝置結果。測試通知仍不進鈴鐺。
7. **補發錯誤**：執行補發不應再出現英文 D1 `LIKE/GLOB` 錯誤；若失敗應顯示中文，今日額度不增加。
8. **人員選擇**：新增／修改電鍍資料，選擇一名焊接人員後儲存；重新開啟仍應是同一人，調整後台人員排序後再試一次。
9. **存檔穩定**：線材資料較多時修改一筆狀態並儲存，不應再出現 `Worker exceeded resource limits`；連點儲存只應送出一次。
10. **時間核對**：後台通知紀錄與手機鈴鐺以台灣時間顯示；實際推播時間可與裝置結果逐台核對。
